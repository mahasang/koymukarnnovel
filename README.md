# koymukarnnovel

เว็บอ่านนิยายออนไลน์ภาษาอังกฤษที่แปลเป็นภาษาไทย เปิดให้ผู้อ่านเข้าอ่านได้โดยไม่ต้องมีบัญชี
เจ้าของวางต้นฉบับทีละหลายตอนในหลังบ้าน ระบบให้ Claude แปลเป็นคิวเบื้องหลัง เจ้าของตรวจแล้วกดเผยแพร่

- **หน้าบ้าน** (`/`): หน้าแรก หน้าเรื่อง หน้าอ่าน (ธีมมืด/กระดาษ/ซีเปีย/ดำสนิท ปรับขนาดและฟอนต์ จำตำแหน่งที่อ่านค้าง) ใช้บนมือถือและติดตั้งเป็นแอป (PWA) ได้
- **หลังบ้าน** (`/admin`): ล็อกอินด้วยรหัสผ่าน แดชบอร์ด จัดการนิยาย ตอน และอภิธานศัพท์ วางข้อความหลายตอนแล้วแยกตอนให้ ตั้งค่า และดาวน์โหลดสำรองข้อมูล
- **คิวแปล**: ทีละตอน หยุดเองเมื่อ API ล่มหรือเครดิตหมด ไม่เสียข้อมูล แล้วกด "ทำต่อ" ได้
- **ช่องทางนำเข้า** (`/api/import`): ส่งคำแปลที่แปลนอกระบบเข้าตอนที่มีอยู่ด้วยโทเค็น โดยไม่เรียก Claude API
- Node + Express + TypeScript, ฐานข้อมูล SQLite ไฟล์เดียว (`node:sqlite` ในตัว Node ไม่ต้องคอมไพล์อะไรเพิ่ม), หน้าเว็บ React + Vite
- เรียก Claude จากฝั่งเซิร์ฟเวอร์เท่านั้น ผู้อ่านสาธารณะทำให้เกิดการเรียก API ไม่ได้ และคีย์ไม่ถูกส่งไปที่เบราว์เซอร์

## สิ่งที่ต้องมี

- **Node.js 22.13 ขึ้นไป** (ต้องการ `node:sqlite`) ตรวจด้วย `node --version`
- คีย์ Claude API ถ้าจะให้ระบบแปลเอง (ไม่มีก็ใช้งานส่วนอื่นได้ รวมถึงวางคำแปลเองและนำเข้าผ่านโทเค็น)
- ถ้าจะเปิดสาธารณะ: โดเมน (ดูหัวข้อ Docker Compose หรือ Cloudflare Tunnel)

## รันในเครื่อง

```bash
npm install
cp server/.env.example server/.env   # แล้วเปิดไฟล์ใส่ ANTHROPIC_API_KEY (ไม่ต้องใส่รหัสผ่านก็ได้ถ้าใช้เฉพาะในเครื่อง)
npm run build
npm start
```

เปิด `http://localhost:8787` สำหรับหน้าเว็บ และ `http://localhost:8787/admin` สำหรับหลังบ้าน
ค่าเริ่มต้นฟังเฉพาะเครื่องนี้ (`127.0.0.1`) จึงเข้าหลังบ้านได้โดยไม่ต้องล็อกอิน
ถ้าตั้ง `ADMIN_PASSWORD` ระบบจะถามรหัสเสมอ และถ้าเปลี่ยน `HOST` ให้เครื่องอื่นเข้าถึงได้ **ต้องตั้ง `ADMIN_PASSWORD`** ไม่งั้นระบบไม่ยอมเริ่ม

พัฒนา: `npm run dev` (หน้าเว็บที่ `http://localhost:5173` ต่อกับหลังบ้านพอร์ต 8787)

### ตัวอย่างข้อมูล

`npm run seed:demo` สร้างนิยายสมมติหนึ่งเรื่อง สามตอน (มีคำแปลไทยครบ) ใช้ดูหน้าตาโดยไม่ต้องมี API key ลบได้จากหลังบ้านเหมือนเรื่องอื่น

## ตัวแปรสภาพแวดล้อม

ตั้งใน `server/.env` (ตัวอย่างพร้อมคำอธิบายอยู่ใน `server/.env.example`) หรือเป็นตัวแปรของระบบ ค่าว่างนับเป็นไม่ตั้ง
**รหัสผ่าน คีย์ และโทเค็นตั้งได้ที่นี่เท่านั้น** หน้าตั้งค่าในหลังบ้านบอกแค่ว่าตั้งแล้วหรือยัง

| ตัวแปร | จำเป็น | ค่าเริ่มต้น | ความหมาย |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | ต้องมีเพื่อให้ระบบแปล | — | คีย์ Claude API |
| `ADMIN_PASSWORD` | ต้องมีถ้า `HOST` ไม่ใช่ loopback | — | รหัสผ่านหลังบ้าน (ควรยาวอย่างน้อย 10 ตัวอักษร) |
| `HOST` / `PORT` | ไม่ | `127.0.0.1` / `8787` | ที่อยู่และพอร์ตที่ฟัง (ใน Docker คือ `0.0.0.0`) |
| `PUBLIC_URL` | แนะนำ | — | เช่น `https://koymukarnnovel.example.com` ใช้สร้างลิงก์สมบูรณ์ใน sitemap / OG / canonical |
| `TRUST_PROXY` | ไม่ | `0` | จำนวนชั้น proxy หน้าแอป (Caddy หรือ Cloudflare Tunnel ชั้นเดียว = `1`) |
| `DB_PATH` | ไม่ | `server/data/koymukarnnovel.db` | ที่เก็บไฟล์ฐานข้อมูล |
| `TRANSLATE_MODEL`, `RECAP_MODEL` | ไม่ | `claude-sonnet-5-5`, `claude-haiku-4-5-20251001` | โมเดลเริ่มต้น (เปลี่ยนในหน้าตั้งค่าได้ด้วย) |
| `SESSION_SECRET` | ไม่ | — | เพิ่มความสุ่มให้ลายเซ็น cookie |
| `IMPORT_TOKEN` | ไม่ | — | โทเค็นช่องทางนำเข้า ยาวอย่างน้อย 24 ตัวอักษร ไม่ตั้ง = ปิดช่องทางนี้ |

สร้างค่าสุ่มสำหรับ `SESSION_SECRET` และ `IMPORT_TOKEN`:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

แก้ค่าในไฟล์แล้วต้องรีสตาร์ทระบบจึงมีผล

## ลองแปลหนึ่งตอนสั้นๆ ด้วยคีย์จริง

ระบบยังไม่เคยทดสอบกับ Claude API จริงตั้งแต่ตอนพัฒนา จึงควรลองก่อนใช้งานจริง:

1. ใส่ `ANTHROPIC_API_KEY` แล้วรีสตาร์ท เปิด `/admin` → **ตั้งค่า** → กด **ทดสอบการเชื่อมต่อ** (ใช้โมเดลสรุปที่บันทึกไว้ ค่าใช้จ่ายน้อยมาก)
2. **นิยาย → เพิ่มนิยายใหม่** ใส่ชื่อเรื่อง (เรื่องใหม่เป็นร่าง ไม่ขึ้นเว็บจนกว่าจะเปิดสวิตช์ "เผยแพร่ให้ผู้อ่านเห็น")
3. **เพิ่มตอน** วางต้นฉบับสั้นๆ สักหนึ่งย่อหน้า ปล่อย "แปลทันที" เปิดไว้ กดปุ่มส่ง
4. ดูข้อความไหลในแดชบอร์ด พอ "แปลเสร็จ" เปิดตอนตรวจ แล้วกดเผยแพร่เมื่อพอใจ (ต้องเผยแพร่ทั้งเรื่องและตอน ผู้อ่านจึงเห็น)

แดชบอร์ดแสดงโทเค็นที่ใช้และค่าใช้จ่ายโดยประมาณ (กรอกราคาโมเดลในหน้าตั้งค่า) ควรตั้งวงเงินรายเดือนที่ Anthropic Console ด้วย

## ช่องทางนำเข้าคำแปล

ไว้ส่งคำแปลที่แปลนอกระบบ เช่นให้ Claude Code แปลในเครื่องแล้วส่งกลับ โดยไม่ผ่านคิวและไม่เสียค่า API ของเว็บ

1. ตั้ง `IMPORT_TOKEN` ใน `server/.env` (ใช้คำสั่งสร้างค่าสุ่มด้านบน) แล้วรีสตาร์ท หน้าตั้งค่าจะแสดงสถานะและตัวอย่างคำสั่ง
2. วางต้นฉบับในหลังบ้านโดยปิด "แปลทันที" ตอนจะเป็นร่าง
3. ส่งคำแปลเข้าตอน (แทน `YOUR_TOKEN` ด้วยโทเค็นจริง และ `https://your-site` ด้วยที่อยู่เว็บ):

```bash
# ดูตอนที่ยังเป็นร่างของเรื่อง 1
curl -H "Authorization: Bearer YOUR_TOKEN" "https://your-site/api/import/novels/1/chapters?status=draft"

# ดูโจทย์ของตอนที่ 3 (ต้นฉบับ + อภิธานศัพท์ + เรื่องย่อล่าสุด + prompt ชุดเดียวกับที่คิวใช้)
curl -H "Authorization: Bearer YOUR_TOKEN" "https://your-site/api/import/novels/1/chapters/3"

# ส่งคำแปลเข้าตอนที่ 3
curl -X PUT -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" \
  -d '{"translation":"ข้อความแปลทั้งตอน","titleTh":"ชื่อตอน","recap":"เรื่องย่อ 2-3 ประโยค"}' \
  "https://your-site/api/import/novels/1/chapters/3/translation"
```

ตอนที่นำเข้าจะเป็น "แปลเสร็จ" แต่ **ไม่เผยแพร่เอง** เปิดตรวจในหลังบ้านแล้วกดเผยแพร่ ถ้าตอนนั้นมีคำแปลอยู่แล้วต้องส่ง `"overwrite": true` ตอนที่เผยแพร่แล้วหรือกำลังถูกคิวแปลอยู่นำเข้าไม่ได้ (ตอบ 409)
ช่องทางนี้ล็อกอินหลังบ้าน ลบ หรือเผยแพร่ไม่ได้ ถ้าโทเค็นรั่วให้เปลี่ยนค่าแล้วรีสตาร์ท และอย่าใส่โทเค็นในสคริปต์ที่แชร์ต่อ

## เปิดสาธารณะด้วย Docker Compose + Caddy

เหมาะกับ VPS ที่มี IP สาธารณะ ต้องมี **โดเมน** ที่ชี้ DNS มาที่เครื่อง และเปิดพอร์ต 80/443 Caddy ขอใบรับรอง HTTPS ให้เอง

```bash
cp server/.env.example server/.env    # ใส่ ADMIN_PASSWORD, ANTHROPIC_API_KEY, PUBLIC_URL (https://โดเมนของคุณ) และ IMPORT_TOKEN ถ้าใช้
echo "DOMAIN=novel.example.com" > .env # โดเมนของคุณ (ไฟล์ .env นี้อยู่ข้าง docker-compose.yml)
docker compose up -d --build
```

- บริการ `app` ฟัง `0.0.0.0:8787` ในเครือข่ายภายใน ไม่เปิดพอร์ตออกเครื่อง ผู้ใช้เข้าผ่าน `caddy` เท่านั้น
- `TRUST_PROXY=1` ถูกตั้งให้แล้ว (มี Caddy ชั้นเดียว) ข้อมูลอยู่ใน volume `koymukarnnovel-data` (`/data`) และ `restart: unless-stopped`
- ดู log: `docker compose logs -f app` · หยุด: `docker compose down` (ไม่ลบข้อมูล ห้ามใส่ `-v` เว้นแต่ตั้งใจลบข้อมูล)

> ไฟล์ Docker เขียนและตรวจ `docker compose config` แล้ว แต่ **ยังไม่เคย build เป็น image จริง** (ตอนพัฒนาไม่มี Docker daemon) ลองรันทีละขั้นและดู `docker compose logs` ถ้าติดปัญหา

## ไม่มี IP สาธารณะ: Cloudflare Tunnel

รันแอปในเครื่องที่บ้านแล้วให้ Cloudflare Tunnel เปิดทางเข้า ไม่ต้องเปิดพอร์ต (ต้องมีโดเมนที่ใช้ Cloudflare จัดการ DNS)

1. รันแอปตามหัวข้อ "รันในเครื่อง" โดยตั้ง `ADMIN_PASSWORD`, `PUBLIC_URL` (https://โดเมนของคุณ) และ `TRUST_PROXY=1`
2. ติดตั้ง `cloudflared` สร้าง tunnel แล้วชี้โดเมนไปที่ `http://localhost:8787` ตามคู่มือของ Cloudflare
3. ถ้ามี proxy อีกชั้นหน้าแอป (เช่น Caddy ต่อหลัง Cloudflare) ให้ตั้ง `TRUST_PROXY=2`

## สำรองข้อมูลและอัปเดต

- **สำรอง**: หลังบ้าน → ตั้งค่า → ดาวน์โหลดไฟล์สำรอง (`.db` ชุดเดียวที่สมบูรณ์ รวมปกนิยาย ไม่มีรหัสผ่าน/คีย์/โทเค็น) ควรทำเป็นประจำ
- **สำรองทั้งโฟลเดอร์**: ถ้าก๊อปไฟล์เอง ให้ก๊อป **โฟลเดอร์ `data` ทั้งโฟลเดอร์** (`server/data` หรือ `/data` ใน Docker) เพราะข้อมูลล่าสุดอาจอยู่ในไฟล์ `-wal` ข้าง `.db` และควรหยุดแอปก่อนก๊อป (Docker: `docker compose stop app` แล้ว `docker compose cp app:/data ./data-backup`)
- **กู้คืน**: หยุดแอป วางไฟล์ `koymukarnnovel.db` ที่สำรองไว้ในโฟลเดอร์ `data` ลบไฟล์ `koymukarnnovel.db-wal` และ `-shm` เดิมที่ค้างอยู่ แล้วเริ่มแอป
- **อัปเดตเวอร์ชัน**: `git pull` แล้ว `npm install && npm run build` แล้วรีสตาร์ท (Docker: `git pull && docker compose up -d --build`) โครงฐานข้อมูลอัปเกรดเองตอนเริ่มระบบ
- **ข้อมูลจากรุ่นต้นแบบ** (`novel-99.db` / `novel-teller.db` ในโฟลเดอร์ `data`): ระบบเปลี่ยนชื่อและแปลงให้เองตอนเริ่มครั้งแรก ทุกเรื่องที่ย้ายมา **ถูกซ่อนไว้ (ยังไม่เผยแพร่)** เข้าหลังบ้านแล้วกดเผยแพร่เรื่องที่ต้องการ ปิดแอปรุ่นเก่าก่อนเริ่ม และรันแอปทีละโปรเซสเท่านั้น

## ภาษา

หน้าบ้านสาธารณะมี UI สามภาษา: ไทย / English / ລາວ — เลือกจากปุ่มภาษาที่หัวเว็บ (จำค่าที่เลือกไว้ในเครื่อง) ถ้ายังไม่เคยเลือกจะดูจากภาษาของเบราว์เซอร์ แล้วใช้ไทยเป็นค่าตั้งต้น

- เนื้อเรื่อง ชื่อเรื่อง และข้อความหน้า เกี่ยวกับ/ติดต่อ ยังเป็นภาษาไทยทุกภาษา (ทำเครื่องหมาย `lang="th"`); หลังบ้านเป็นไทยเสมอ; เสียงอ่านยังเป็น `th-TH`; URL, meta/OG และ sitemap ไม่เปลี่ยน
- วันที่: ไทยใช้ พ.ศ. ส่วน English/ລາວ ใช้ ค.ศ.; ตัวเลขเป็นเลขอารบิกทุกภาษา
- ข้อความอยู่ใน `web/src/i18n/{th,en,lo}.ts` (`th.ts` เป็นต้นแบบ — `en.ts`/`lo.ts` ต้องมีคีย์ครบตามชนิดข้อมูล ไม่งั้น `npm run typecheck` และเทสต์จะไม่ผ่าน) แก้คำลาวที่ `web/src/i18n/lo.ts`
- ดูคำแปลทั้งหมดเทียบกัน: `docs/superpowers/verification/i18n-review.md` (สร้างใหม่ด้วย `node --import tsx web/scripts/i18n-review.mts > docs/superpowers/verification/i18n-review.md`)

## ข้อควรรู้เรื่องลิขสิทธิ์

การแปลและเผยแพร่นิยายที่ยังมีลิขสิทธิ์โดยไม่ได้รับอนุญาตเป็นการละเมิดลิขสิทธิ์ในเกือบทุกประเทศ เพราะงานแปลเป็นงานดัดแปลง
การใส่เครดิตหรือลิงก์ต้นฉบับ **ไม่ได้ทำให้ถูกกฎหมาย** เว็บเปิดสาธารณะเสี่ยงโดนแจ้งลบ ถูกปิดโดเมนหรือโฮสต์ หรือถูกฟ้องร้อง

- เลือกเผยแพร่เฉพาะงานที่ได้รับอนุญาตจากผู้แต่ง งานที่ใช้สัญญาอนุญาตแบบเปิด งานที่หมดอายุลิขสิทธิ์ หรืองานของตัวเอง
- ระบบมีเครื่องมือช่วยลดความเสี่ยง: ช่องเครดิตผู้แต่ง/ลิงก์ต้นฉบับ/บันทึกสิทธิ์ต่อเรื่อง ป้าย "แปลโดย AI" หน้าติดต่อ/แจ้งลบ ซ่อนทั้งเรื่องได้คลิกเดียว และไม่เผยแพร่อัตโนมัติ (แดชบอร์ดเตือนถ้ายังไม่ได้ใส่ช่องทางติดต่อ)
- **เมื่อมีคำขอแจ้งลบ ให้ซ่อนเรื่องนั้นทันที** (หลังบ้าน → นิยาย → เปิดเรื่องนั้น → ปิดสวิตช์ "เผยแพร่ให้ผู้อ่านเห็น" แล้วบันทึก) แล้วค่อยตรวจสอบและตอบกลับผู้แจ้ง
- ถ้าจะใช้เชิงพาณิชย์หรือจริงจัง ควรปรึกษาผู้เชี่ยวชาญด้านกฎหมายในประเทศที่โฮสต์และประเทศของผู้อ่าน

คำแปลจาก AI อาจมีข้อผิดพลาด จึงมีป้ายกำกับ อภิธานศัพท์ต่อเรื่อง และแก้คำแปลเองได้ในหน้าแก้ตอน
