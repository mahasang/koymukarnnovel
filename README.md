# Novel 99

แอปส่วนตัวสำหรับอ่าน/ฟังนิยายออนไลน์ภาษาอังกฤษเป็นภาษาไทย ทีละตอน
วางเนื้อหาตอนจากเว็บต้นฉบับ แล้วให้ Claude แปลเต็ม เล่าเรื่อง หรือสรุปเป็นภาษาไทย

- **หลังบ้าน**: Node + Express + TypeScript, เก็บข้อมูลใน SQLite (`node:sqlite` ในตัว Node ไม่ต้องคอมไพล์อะไรเพิ่ม)
- **หน้าเว็บ**: React + Vite + TypeScript ใช้บนมือถือได้ และติดตั้งเป็นแอป (PWA) ได้
- **เรียก Claude** จากฝั่งเซิร์ฟเวอร์เท่านั้น API key ไม่ถูกส่งไปที่เบราว์เซอร์

## ติดตั้งและรัน

ต้องใช้ Node 22.13 ขึ้นไป

```bash
npm install
cp server/.env.example server/.env   # แล้วใส่ ANTHROPIC_API_KEY
npm run dev                          # หน้าเว็บ http://localhost:5173 (หลังบ้านพอร์ต 8787)
```

ใช้งานจริง (build แล้วให้เซิร์ฟเวอร์เสิร์ฟหน้าเว็บเอง):

```bash
npm run build
npm start                            # http://127.0.0.1:8787
```

## วิธีใช้

1. **เพิ่มเรื่อง** ใส่ชื่อเรื่อง ลิงก์ต้นฉบับ (ไว้จำเฉยๆ) และสไตล์ที่อยากได้ เช่น "แนวกำลังภายใน ใช้ภาษากึ่งโบราณ"
2. **เพิ่มตอน** คัดลอกเนื้อหาตอนจากเว็บมาวาง
3. **อภิธานศัพท์** ใส่ชื่อตัวละคร สถานที่ ศัพท์เฉพาะ พร้อมคำไทยที่ตกลงไว้ ระบบส่งให้ Claude ทุกครั้งที่แปล
4. เปิดตอนแล้วเลือกโหมด **แปลเต็ม / เล่าเรื่อง / สรุป** กดแปล ข้อความจะไหลออกมาทีละส่วน
5. กด **🔊 ฟัง** เพื่อให้เบราว์เซอร์อ่านออกเสียงภาษาไทย (ใช้เสียงที่มีในเครื่อง)

ความต่อเนื่องของเรื่อง: หลังแปลแต่ละตอน ระบบสร้างเรื่องย่อสั้นๆ เก็บไว้ แล้วแนบเรื่องย่อ 5 ตอนล่าสุดไปกับการแปลตอนถัดไป
ตอนยาวจะถูกแบ่งเป็นช่วงๆ และส่งท้ายช่วงก่อนหน้าไปเป็นบริบท คำแปลที่ได้แล้วถูกเก็บไว้ จึงไม่เสียค่า API ซ้ำเมื่อเปิดอ่านอีกครั้ง

## ใช้บนมือถือ

PWA คือเปิดหน้าเว็บบนมือถือแล้วเลือก "เพิ่มลงหน้าจอหลัก" ก็ใช้เหมือนแอป วิธีให้มือถือเข้าถึงเซิร์ฟเวอร์:

- **วง Wi-Fi เดียวกัน**: ตั้ง `HOST=0.0.0.0` และ `ACCESS_TOKEN` ใน `server/.env` แล้วเปิด `http://<IP เครื่องคอม>:8787` จากมือถือ
- **ใช้ได้ทุกที่**: นำไปรันบนเซิร์ฟเวอร์ส่วนตัว (VPS) หลัง HTTPS และตั้ง `ACCESS_TOKEN` เสมอ
  (PWA ติดตั้งได้ต้องผ่าน HTTPS ยกเว้น localhost)

ถ้าต่อไปอยากได้แอปมือถือเนทีฟ (Expo / React Native) หลังบ้านนี้ใช้ต่อได้เลย เขียนเฉพาะหน้าจอใหม่

## ข้อควรรู้

- **ลิขสิทธิ์**: เหมาะกับการใช้ส่วนตัว ไม่ควรเผยแพร่คำแปลหรือเปิดเป็นบริการให้คนอื่นโดยไม่ได้รับอนุญาตจากเจ้าของงาน
- **ต้นฉบับ**: แอปไม่ดึงเนื้อหาจากเว็บอื่นเอง ให้วางเนื้อหาเข้ามา เลี่ยงปัญหาข้อกำหนดการใช้งานของเว็บต้นทาง
- **ค่าใช้จ่าย**: คิดตามปริมาณข้อความที่ส่งและรับ เปลี่ยนโมเดลได้ที่ `TRANSLATE_MODEL` และ `RECAP_MODEL` ใน `.env`
- **ความปลอดภัย**: ค่าเริ่มต้นเปิดเฉพาะในเครื่อง (`127.0.0.1`) ถ้าเปิดให้เครื่องอื่นเข้าถึงต้องตั้ง `ACCESS_TOKEN`

```
web/src/pages/         Library, Novel, Reader
web/src/useSpeech.ts   อ่านออกเสียงด้วย Web Speech API
```
