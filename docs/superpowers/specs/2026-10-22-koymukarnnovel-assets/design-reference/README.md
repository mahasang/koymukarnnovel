# ไฟล์อ้างอิงดีไซน์ (ไม่ใช่โค้ดของแอป)

สคริปต์ที่ใช้สร้าง mockup ที่ผู้ใช้อนุมัติแล้ว เก็บไว้เพื่อให้ตอนลงมือทำมี token สี, CSS, และโครงหน้า (layout) ให้ดูเป็นต้นแบบ

- `build.mjs` — theme tokens (midnight / paper / sepia), CSS ของหน้าสาธารณะ, ปกตัวอย่างที่เขียนด้วย CSS/SVG, หน้า home / มือถือ / reader
- `admin.mjs` — CSS และโครงหน้า admin (dashboard, วางข้อความ + ตรวจจับตอน, ตารางตอน)

ใช้เปิดดูและคัดลอก CSS ไปปรับใช้เท่านั้น ถ้าจะรันซ้ำต้องมี `@fontsource/prompt`, `@fontsource/sarabun`, `@fontsource/noto-serif-thai` ติดตั้งอยู่ข้างๆ
ภาพที่ได้จากสคริปต์เหล่านี้อยู่ในโฟลเดอร์พี่น้อง `*.jpg`

> หมายเหตุ: ภาพ `*.jpg` ในโฟลเดอร์พี่น้องเรนเดอร์ไว้ก่อนเปลี่ยนชื่อโปรเจกต์ จึงยังเห็นโลโก้ "99" และชื่อ Novel 99 ในภาพ สคริปต์ชุดนี้ใช้ชื่อ koymukarnnovel (โลโก้ "K") แล้ว ถ้ารันซ้ำจะได้ภาพตามชื่อปัจจุบัน
